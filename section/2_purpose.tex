本研究の目的は、現行システムの定型条件フィルタリングの限界を超え、\textbf{ワーカーと求人の「意味的・潜在的な親和性」を多角的に捉える}ことで、双方の検索・推薦の手間を最小化し、マッチング精度を向上させることである。

具体的には、以下の3つの側面から改善を図る：

\begin{enumerate}
\item \textbf{意味的類似性の導入:} 求人の記述テキストとワーカーの志向の\textbf{意味的な近さ}を導入し、従来の「介護種別」といった粗いカテゴリ分類を超えた精緻なマッチングを実現する。

\item \textbf{行動履歴の活用:} ワーカーの過去の応募・勤務履歴から志向性を推定し、明示的な条件指定に依存しない推薦を実現する。

\item \textbf{時間要因の考慮:} 志向の変化や履歴の鮮度を反映し、古い履歴の影響を適切に制御する。

\end{enumerate}

\section{従来のマッチングシステムの限界}
従来のマッチングシステムが抱える構造的課題（定型条件中心による意味的マッチングの欠如、履歴活用の不足、利便性要因の取り込み困難など）は、第1章\ref{sec:current-matching-limitations}で述べた通りである。本章ではこれらの課題を前提として、以降で本研究の目的とアプローチを整理する。

\section{本研究のアプローチ}
本研究では、上記の課題に対して「意味的類似性」「履歴情報」「時間要因」を統合してスコアリングする方針を採用する。手法の具体化（類似度計算、履歴からの嗜好ベクトル、重み付けの統合）は第3章で述べ、評価は第4章以降で示す。

\section{期待される効果}
本研究により、以下の効果が期待される：

\begin{itemize}
\item \textbf{ワーカー側：}検索条件の入力が不要となり、過去の行動から自動的に適切な求人が推薦される。職種名や介護項目の表記ゆれに左右されにくくなり、気づいていなかった求人の提示も増える。リピート施設の発見が容易になり、勤務実績のある施設への応募がスムーズになる。さらに、条件調整にかかる時間が短縮され、新しい施設への応募ハードルが低減する。
\item \textbf{事業者側：}適切なワーカーへの求人提示が自動化され、募集から応募までの導線が短縮される。求人の露出が「条件一致」に偏らず、業務内容や相性に基づいた候補に届くため、採用効率が向上する。ミスマッチによるキャンセルや早期離職が減少し、採用コストと現場負担の抑制が期待できる。
\item \textbf{システム全体：}マッチング精度の向上により、プラットフォーム全体の取引量と満足度が向上する。ワーカーと事業者の双方が適切な相手を早期に見つけられるため、応募から就業までのサイクルが短くなる。結果として、継続的な利用や再応募が増え、サービスの信頼性と定着率の向上につながる。
\end{itemize}

これらのアプローチを通じて、介護業界における人材マッチングの効率化と、ワーカー・事業者双方の満足度向上を目指す。
